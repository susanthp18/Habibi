A retry that fails to place strands the case permanently: when the attempt to
place/re-queue a cadence step fails, the case never returns to the queue and no
error surfaces. Read the exact code first. Required: on placement failure,
either requeue with backoff consistent with the existing ladder rules or mark
the case with an explicit terminal/needs-attention state — pick whichever the
surrounding design already uses for similar failures (look at how bot_worker
logs and how other loops handle transient failure), and log it at WARNING/ERROR
with case id. A silent strand is the bug; the resolution mechanism should match
house style.

--- FIX 2: pause does not stop open ladders — cadence.py ~304 ---

to schedule attempts. Required: at the point a ladder decides to fire, check
the campaign's current status (join/fetch as the code already does elsewhere)
and stop/skip if paused — do not delete queued rows; just gate the firing so
pause takes effect within one poll cycle. Log skipped firings at INFO with
campaign id.
