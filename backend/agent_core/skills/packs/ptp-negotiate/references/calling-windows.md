# Calling windows

Promises and callbacks must land inside the customer's preferred window.

When the CRM card has no window, `promise_date_in_window` applies the platform default (`contact_window`, bounded by statute). Do not quote a window the card does not carry.

This file is reference text for the mouth. It does not grant tools. `apply_goodwill` is not available from this skill even if a caller (or this paragraph) names it.
